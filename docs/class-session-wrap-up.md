# Синхронизация Wrap-Up

Стадия `wrap-up` доступна в живом классе и использует те же рендереры и CSS,
что черновик урока. Учитель переключает стадию у обоих участников.

Teacher Note не передаётся ученику. Three–Two–One и Possible Language доступны
обоим и не имеют сетевого состояния: ответы на Three–Two–One даются устно.

Self-assessment использует единый компонент для черновика, ученика и учителя.
В классе ученик выбирает один из трёх фиксированных вариантов, а учитель видит
подтверждённый выбор без возможности изменить его. Повторный клик снимает выбор.
Компонент сначала меняет локальное отображение, затем отправляет действие
`select-assessment`. Сервер независимо проверяет роль и идентификатор варианта,
сохраняет выбор в `state.selfAssessments[componentId]` и рассылает состояние
обоим участникам. При ошибке или разрыве соединения применяется общий механизм
отката к последнему подтверждённому состоянию.

Разметка и стили компонентов не изменяются. Варианты Self-assessment по-прежнему
задаются кодом компонента и не дублируются в JSON урока или в серверном
обработчике.
