# Живой класс: Warm Up

Реализован тестовый проход первой стадии для одного учителя и одного ученика.
Остальные стадии видны, но недоступны. В черновике и библиотеке доступны все стадии.

## Общий интерфейс

`lesson-editor.html` и CSS компонентов используются во всех режимах.
`assets/lesson-view.js` содержит единственный реестр рендереров, отображение стадий
и навигацию. `lesson-editor.js` передаёт настройки редактирования и сохранения;
`class-session.js` — роль, состояние и обработку действий. CSS и разметка
содержимого контролов не менялись.

`ThisOrThat` поддерживает `selections`, `interactive`, `onAction`, а возвращаемый
элемент — `updateState(selections)` и `setInteractive(boolean)`. Обновление состояния
не пересоздаёт DOM и не вызывает `onAction`. Локальный выбор и удалённое состояние
используют одну функцию отображения. Сетевой код находится только в контроллере класса.

## Доступ и состояние

- Учитель открывает `/classes/:id` из расписания с существующей авторизацией.
- `/join/:token` создаёт гостевую cookie для конкретного класса и перенаправляет
  на `/classes/:id/student`, даже если в браузере уже авторизован учитель.
- Гостевая сессия действует семь дней, хранится в БД в виде хеша токена.
  Она даёт доступ только к разрешённому содержимому и его файлам в этом классе.
- Ученик получает список стадий и три публичных блока Warm Up; учительские заметки
  и содержимое следующих стадий сервер не передаёт.
- `/api/classes/:id/live?role=teacher|student` возвращает начальное состояние.
  `/ws/classes/:id?role=teacher|student` проверяет cookie, принадлежность классу и Origin.
- Одновременно активна одна ученическая вкладка. Подключение той же сессии заменяет
  предыдущую вкладку (код 4001, без автоматического переподключения старой вкладки).
  Другой браузер при занятом месте получает 4003. После освобождения места он
  может подключиться повторно. Учитель также имеет одну активную вкладку класса.
- Учитель наблюдает; сервер запрещает ему отправлять ответы. Ученик не может
  менять стадию. Пока единственное разрешённое значение стадии — `warm-up`.
- `class_live_state` хранит текущие выборы и версию отдельно от копии урока.
  История действий не сохраняется. После перезапуска сервера восстанавливается
  последнее подтверждённое состояние.

Клиент отправляет `select-option` с идентификаторами компонента, пары, варианта,
стадии и ожидаемой версией. Сервер проверяет действие, сохраняет состояние и
рассылает действие с новым состоянием обоим участникам. Устаревшая версия отклоняется.
Быстрые клики отправляются последовательно по мере подтверждения предыдущих.
У ученика выбор отображается сразу. При обрыве связи неподтверждённая очередь
сбрасывается с уведомлением; автоматическое переподключение получает снимок сервера.
Во время разрыва ответы заблокированы. Пропущенные действия не проигрываются.

Таймер в живом классе пока скрыт: синхронизация времени в этот объём не входит.
Прокрутка и раскрытие заметок учителя локальны. Текстовый ввод, неправильные попытки
и кратковременные реакции других контролов ещё не реализованы. Формат сообщений
разделяет действие и состояние, но реализация и тесты пока покрывают только выбор
в `ThisOrThat`.

Приложение рассчитано на один процесс Node.js. Отдельного брокера сообщений нет.
WebSocket-маршруты видеозвонка и класса распределяет общий обработчик upgrade;
состояние урока не зависит от подключения видеозвонка.

## Ручная проверка

Автоматические проверки: `npm run check`. Браузерная проверка оставлена владельцу задачи.

1. Создать класс из урока с Warm Up. Открыть его из расписания, а ссылку приглашения
   — в другой вкладке или браузере. Ученику не нужны логин и пароль.
2. Выбирать и быстро менять картинки. У учителя должны совпадать выделение и
   затемнение вариантов; его клики не меняют ответ. Учительские заметки есть только у учителя.
3. Перезагрузить обе страницы: выбор восстановится. Проверить, что остальные стадии
   недоступны в классе, а черновик и библиотека сохранили обычную навигацию.
4. Открыть ученический URL ещё в одной вкладке того же браузера: первая отключится.
   Открыть приглашение в отдельном браузере при занятом месте: появится сообщение
   «Ученик уже подключён». Закрыть активную вкладку и повторить подключение.
5. Прервать связь и восстановить её: появится статус переподключения, затем вернётся
   подтверждённый выбор. Отдельно сравнить внешний вид контента с черновиком.
