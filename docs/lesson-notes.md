# Заметки к уроку

В боковой панели доступны вкладки «План урока» и «Заметки». Выбор вкладки и
прокрутка локальны. Заметки общие для всего занятия и независимы от стадий и
Teacher’s Notes внутри заданий. Поддерживаются абзацы, жирный, курсив,
маркированные списки и жёлтое выделение. Кнопок undo/redo нет.

## Жизненный цикл

- Автор редактирует заметки черновика со статусом `review`. Автосохранение через
  `GET/PUT /api/lesson-drafts/:id/notes`, с проверкой владельца и отдельной версии.
  Локальная резервная копия хранится в localStorage; конфликт другой вкладки
  оставляет текст в редакторе и предлагает скопировать его перед перезагрузкой.
- Публикация ждёт автосохранения заметок. `notes_json` копируется в `content.notes`
  опубликованного урока. Библиотека показывает заметки только для чтения.
- Создание занятия уже копирует контент урока; заметки копируются вместе с ним.
  Изменения в черновике/библиотеке не затрагивают существующие занятия.
- При первом открытии заметок занятия сервер однократно создаёт Y.Doc из
  заготовки и сохраняет в `class_notes`. Клиенты заготовку не вставляют.
- Учитель и ученик редактируют один документ занятия. Ответы и навигация
  продолжают использовать прежний протокол и версии, независимо от заметок.

## Реализация

`assets/src/lesson-notes.js` — Tiptap, интерфейс и клиентский транспорт.
`lib/lesson-notes-config.js` задаёт общую конфигурацию редактора, а
`lib/lesson-notes-schema.js` — ограничения JSON и хранение черновика.
`lib/lesson-notes-store.js` хранит бинарное состояние Yjs в SQLite.
`lib/lesson-notes-signaling.js` обслуживает `/ws/notes/:classId?role=teacher|student`
в существующем Node.js-процессе. Внешних облачных сервисов нет.

Транспорт использует JSON-конверты с Base64 бинарных обновлений Yjs:
`hello` содержит состояние и state vector сервера, `sync` — разницу клиента
и идентификатор отправки, `ack` — подтверждение записи в SQLite, `update` —
правки другого участника. Идентификатор подтверждает только свою отправку.
Алгоритм объединения, state vectors и идемпотентность обеспечивает Yjs.
Сервер валидирует обновление на копии документа до изменения общего состояния.
Только после сохранения сервер подтверждает отправку и рассылает правки.

Доступ проверяется при подключении и каждом изменении; используются существующие
cookie и проверка Origin. В комнате одна вкладка каждой роли; новая вкладка
той же сессии заменяет старую, другой гостевой браузер получает отказ.
Heartbeat обнаруживает оборванные соединения. Комнаты выгружаются после ухода
последнего участника; восстановление идёт из SQLite.

Клиент занятия хранит документ через y-indexeddb, с ключом занятия и авторизованной
сессии. Локальные изменения после разрыва связи объединяются с серверными при
переподключении. После перезагрузки сначала проверяется доступ по сети, затем
подгружается локальная копия. Полностью автономный запуск страницы без сети не
поддерживается. «Сохранено» означает подтверждённую запись на сервере, а не просто
подключённый WebSocket. При неподтверждённых изменениях есть предупреждение об уходе.

Лимиты: 256 КБ содержимого JSON, 2 МБ бинарного состояния Yjs (включая историю CRDT),
глубина структуры 12 и 10 000 узлов. Превышение лимита или отказ сервера сохраняет
текст в клиенте для копирования; при отказе live-редактор блокируется.
Автоматическая очистка локальных копий после занятия пока не предусмотрена.

## Сборка и проверка

`npm run build:notes` собирает `assets/lesson-notes.bundle.js` через esbuild.
Bundle хранится в репозитории, чтобы обычный `npm start` не требовал сборщика.
`npm run check` пересобирает bundle и запускает автотесты, включая заметки.

Автотесты проверяют права и HTTP API, конфликт версий черновика, публикацию,
копирование, слияние одновременных правок, повторную доставку, удаление,
восстановление из SQLite и переподключение WebSocket. Миграция 013 добавляет
хранение заметок и сохраняет существующие уроки и занятия.

Браузерные проверки выполняет пользователь:

1. В черновике открыть «Заметки», ввести текст, применить все четыре вида
   форматирования, вставить текст из другого приложения и перезагрузить страницу.
2. Опубликовать урок, создать два занятия: начальные заметки совпадают,
   последующие изменения одного занятия не меняют другое и черновик.
3. В одном занятии открыть учителя и ученика в разных браузерных профилях;
   одновременно писать в одном абзаце, выделять текст, добавлять/удалять списки.
4. Переключить стадию и вкладки: текст, фокус при изменении стадии и выбранная
   вкладка не должны сбрасываться. Убедиться, что Teacher’s Notes не раскрыты.
5. Отключить сеть у одного участника, писать у обоих, вернуть сеть. Проверить
   объединение правок и статус «Сохранено». Повторить с перезагрузкой страницы.
6. Открыть черновик в двух вкладках: при конфликте локальный текст остаётся
   доступным для копирования. Проверить узкий экран и управление вкладками с клавиатуры.

Прод в рамках этой задачи не обновлялся.
