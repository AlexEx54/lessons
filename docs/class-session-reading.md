# Синхронизация Reading

В классе доступна стадия `reading`: общий `textReading` с иллюстрациями и квизы
`multipleChoice` для gist и detail. Teacher Note и Answer Key с политикой
`teacherOnly` не передаются ученику. Разметка и CSS компонентов сохранены.

`multipleChoice` использует общую функцию `ExerciseState.apply` в черновике,
локальном клиенте класса и на сервере. Компонент принимает `exerciseState`,
`interactive`, `onAction` и `presentation`; `updateState` и `setInteractive`
обновляют существующие кнопки без отправки событий. Авторский нормализатор
остаётся строгим, редактор работает с прежним JSON.

Ученический `presentation` содержит ответы для немедленной локальной проверки.
До выбора правильные варианты в интерфейсе не отмечаются, пояснение появляется
после правильного ответа. Ключ доступен через DevTools. Учитель видит прежние
подсказки правильных вариантов, но отвечать в классе может только ученик.

Действие `choose-option` содержит `stageId`, `componentId`, `itemId`, `value`;
очередь добавляет `expectedVersion`. Сервер проверяет роль, стадию, версию,
существование варианта и блокировку уже решённого вопроса. Переданный клиентом
статус не используется. Результат сохраняется в
`exercises[componentId].answers[itemId]` как `{ value, status }`.
Неверный ответ можно исправить, верный блокирует вопрос.

Клик сразу обновляет компонент, затем отправляется через существующую очередь.
Адаптер накладывает ожидающие действия на подтверждённое состояние теми же
правилами. Подтверждение не пересоздаёт DOM и не отправляет повторное действие.
Ответы сохраняются при смене стадии, перезагрузке и перезапуске сервера.
Ошибка или потеря связи откатывает неподтверждённые действия; до подключения
ответы блокируются. SQL-миграция не требуется.

Автоматические проверки входят в `npm run check`: локальная реакция до отправки,
обновление DOM без эха, откат, права и валидация, совпадение локальных и серверных
правил, доставка через пару WebSocket и восстановление после перезапуска.
Браузерную проверку визуала выполняет пользователь.
