# Sentence Builder

Компонент `sentenceBuilder` — игра «собери предложение из карточек». В шаблоны уроков он попадает через блок
«Собрать предложение» (контрол `sentenceBuilder`, группа «Грамматика»), см. раздел «Блок шаблона» ниже.
Сохранённые ранее черновики и снимки уроков не мигрируются. После изменения серверного кода перезапустите процесс приложения.

## Блок шаблона

`lib/template-controls/sentence-builder.js`. Параметры: число предложений (2–12, по умолчанию 6), подсказки,
поздравление в конце; оформление — заголовок и инструкция.

Нейросеть возвращает для каждого предложения `sentence` и `otherOrders`. В `sentence` слова разделены пробелами,
фраза в `[скобках]` — одна карточка; просим от 3 до 10 карточек (вне диапазона — предупреждение в логе).
`otherOrders` — до трёх других верных порядков тех же карточек. Порядок, собранный из других карточек, убирается
с предупреждением, а не валит урок: иначе игра требовала бы невозможного ответа. Сломанные скобки в основном
предложении и повторяющиеся предложения — ошибка генерации.

Пример для синтетики и каталога — 12 предложений на should / shouldn't о телефонах в школе; тесты компонента
берут его через `test/helpers/sentence-builder.js`.

## Настройка

После подключения компонента к уроку нажмите «Редактировать» над планшетом в редакторе черновика.
Можно изменить заголовок, инструкцию, поздравление, разрешение подсказок и 1–12 предложений.
Первая строка поля — основной ответ; следующие — другие допустимые порядки тех же карточек.
Квадратные скобки объединяют слова в карточку:

```text
Today we can [help people].
we can [help people]. Today
```

Пунктуация после закрывающей скобки прикрепляется к этой карточке.
Варианты используют одинаковые тексты, регистр и пунктуацию; одинаковые слова взаимозаменяемы.
В предложении 2–18 карточек, до 8 вариантов ответа. Массовое добавление принимает по одному предложению на строке.

## Игра

Нажатие переносит слово в конец ответа; повторное нажатие возвращает его в набор.
Перетаскивание меняет позицию, Alt + ←/→ переставляет выбранную карточку в ответе.
Лапка сопровождает каждый перенос. Hint исправляет первое несовпадение, сохраняя самый длинный правильный префикс одного из допустимых ответов.
Check проверяет полный ответ; переход к следующему предложению возможен после успеха.
Финал показывает радостного кота и настраиваемое поздравление.
При reduced motion и восстановлении состояния анимация не воспроизводится.

## Состояние и интеграция

- Редактор сохраняет конфигурацию через `PATCH /api/lesson-drafts/:draftId/sentence-builder/:componentId`; действуют существующие права владельца и статус review.
- Учитель и ученик пользуются общим состоянием класса: порядок карточек, текущая фраза, попытки, подсказки, решения и завершение сохраняются в SQLite.
- Идентификаторы карточек и перемешивание создаются один раз на класс. Ученический payload не содержит правильных порядков.
- Сервер проверяет ответы и выдаёт подсказки; клиент предварительно показывает только перемещения.
- Существующий reset-stage очищает прогресс, сохраняя исходное перемешивание.
- Старые версии действий отклоняются существующей проверкой версии класса. При потере подключения управление блокируется.

Модель и валидация: `assets/components/sentence-builder-model.js`.
UI и редактор: `assets/components/sentence-builder.js` и `.css`.
Локальный предпросмотр: `/assets/sentence-builder/index.html` — настройки хранятся только в localStorage, прогресс демонстрации сбрасывается при загрузке.

## Проверка

`npm run check` включает модель, рендерер, редактор, анимацию, drag-and-drop, HTTP-сохранение и общий прогресс класса после повторного открытия базы.
В браузере проверены прохождение до финала, сохранение настроек, переносы и адаптивная ширина 375 px.
